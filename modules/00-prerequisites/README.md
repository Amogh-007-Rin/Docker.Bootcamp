# Module 00 — Prerequisites
[Previous: Repository Home](../../README.md) | [Next: Module 01 — Introduction](../01-introduction/README.md)

## What you learn
- You refresh Linux file system, permissions, and process basics.
- You understand OS-level virtualization and why containers exist.
- You compare virtual machines and containers at a conceptual level.

## Prerequisites
- You can use a terminal and edit text files.
- You have basic Linux navigation skills.

## Estimated time
- 60–90 minutes
